# Verification

Run `python3 -m unittest discover -s tests` and `python3 tools/build-manifest.py`. Verify that the manifest has a nonempty version and one entry per file in `Themes/`. Verify hashes, byte counts, repository-scoped URLs, and the free, read-only Affiliate flow in Clink. Electronic-paper themes print every legend, frame and suggestion in the panel's single pigment, tinted from the theme's own text colour: check that an affiliate's colour arrives as a recognisable hue and that the legends still read against their caps.
